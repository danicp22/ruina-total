## 🎲 De qué va

Al nacer, la vida tira los dados: te puede tocar una familia **pobre**, **de clase media** o **rica**. A partir de ahí, decides tú:

- 🏫 Estudiar, suspender, buscar trabajo o montártelo por tu cuenta.
- ❤️ Ligar, tener pareja, irte a vivir juntos, casarte, tener hijos... o no.
- 🏠 Alquilar o comprar casa en la inmobiliaria: desde una autocaravana hasta un chalet con piscina.
- 🚗 Comprarte un coche (o «tomarlo prestado») y conducir por el barrio.
- 🪩 Salir de fiesta a la discoteca Pachanga.
- ⛓️ Acabar en la cárcel, hacer amigos dentro y planear una fuga.
- 📰 Salir en el periódico del barrio, hacer fotos y llenar el álbum de tu vida.

Cada partida es distinta. Cada vida termina igual: con tu esquela, el título de tu vida y tu vida en números.

🏅 Y hay **34 vidas posibles** que coleccionar entre partidas: nacer pobre y morir rico, fugarte de la cárcel, vivir en una autocaravana... ¿Cuántas conseguirás?

## 🌐 Jugar sin instalar

Entra en **[danicp22.github.io/ruina-total](https://danicp22.github.io/ruina-total/)** y juega directamente en el navegador (Chrome, Firefox, Edge...). La partida se guarda en ese navegador.

## ⬇️ Cómo instalarlo

Entra en **[Releases](https://github.com/danicp22/ruina-total/releases/latest)** y descarga el archivo de tu sistema.

### 🐧 Linux (Ubuntu, Debian, Mint...)
Descarga `RuinaTotal-linux.deb`, abre una terminal en la carpeta de descargas y escribe:
```bash
sudo apt install ./RuinaTotal-linux.deb
```
El juego aparece en tus aplicaciones como **Ruina Total**. Para desinstalarlo:
```bash
sudo apt remove ruina-total
```

### 🪟 Windows
Descarga `RuinaTotal-windows.exe` y ábrelo. No hace falta instalar nada.

> Windows puede avisarte de que «protegió su PC», porque el juego no tiene firma digital (cuesta dinero). Pulsa **Más información → Ejecutar de todas formas**.

## 🎮 Controles

| Acción | Teclado | Móvil |
|---|---|---|
| Moverse / conducir | `WASD` o flechas | Joystick en pantalla |
| Interactuar | `E` o `Espacio` | Botón de acción |
| Elegir opción | `1` `2` `3` `4` | Tocar |
| Móvil del personaje | `M` | 📱 |
| Modo foto | `F` | 📸 |
| Pausa y ajustes | `Esc` o `P` | ⏸ |
| Pantalla completa | `F11` | — |

En **Pausa** puedes cambiar el volumen, la calidad gráfica (si el juego va lento, bájala), el tamaño del texto y la velocidad del tiempo.
